# Simple AI Agent

## Overview

`simple_AI_agent.py` implements a terminal based AI assistant powered by Google Gemini. It:
- Accepts natural‑language input from the user.
- Answers two private house‑related questions (color and city) without calling the LLM.
- Forwards all other queries to the Gemini model (primary and optional fallback).
- Logs every prompt, response, tool call, and Gemini interaction to `ai_agent.log` in a line‑delimited JSON format, masking the API key for security.

## Prerequisites

- Python 3.9+ installed.
- A Google Gemini API key. Create a `.env` file in the project root with:
  ```
  GOOGLE_API_KEY=your_gemini_api_key
  ```
- (Optional) Set `MODEL` and `FALLBACK_MODEL` environment variables to select specific Gemini models. Defaults to `gemini-1.5-flash`.
- Install dependencies:
  ```bash
  pip install -r requirements.txt
  # or, if a requirements file is not present:
  pip install python-dotenv google-generativeai
  ```

## Running the Agent

```bash
python simple_AI_agent.py
```
You will see a prompt like:
```
Simple AI Agent – type your question (Ctrl‑C to quit)

>>> 
```
Enter any question. The agent will either answer the private house questions directly or forward the request to Gemini and display the response.

All interactions are appended to `ai_agent.log`. Each line is a JSON object, for example:
```json
{"timestamp":"2026-09-08T22:20:00Z","type":"prompt","content":"What is the weather?","separator":"=== PROMPT ==="}
```
The log can be inspected with any JSON viewer or simply `cat ai_agent.log`.

## Stopping the Agent

Press `Ctrl‑C` or send an EOF (e.g., `Ctrl‑D`) to exit gracefully.
