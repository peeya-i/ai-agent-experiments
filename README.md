## class_grader_2
This grader will evaluate the implementation against the criteria outlined in 3 documents:
- **Hard Requirements for the Assignment** This is set by the instructor in SUBMISSIONS.yaml in the grader app folder
- **Grading Rubric** outlined in SCORING.md in the grader app folder
- **Spec for the Application** in the SPECIFICATIONS.md file in assignment submission (student's) repo folder

This grader was created using only prompts in Antigravity IDE with Gemini 3.7 Medium model. I provided the scoring rubric SCORING.md.
After it was discovered that the grader doesn't penalize the submissions for not having AI Agent, the SUBMISSIONS.yaml (hard requirements) was created and submitted to the IDE prompts.

The prompts used to create and update the app are included in the file Prompts.md in the folder.


## travel-itinerary-builder
This is app that creates a personalized travel itinerary for a given destination including flight and hotels. The app requires 
the user to enter the city of origin, destination, number of days, and max budget. The app also allows the user to enter the types of activities that they are intrested in. The app will use the types of activities to create a personalized itinerary. It will use the budget to find flights, hotels, and activities that fit within the budget.

This app was created by Antigravity with Gemini 3.7 Medium model. The IDE was given the SPECIFICATIONS.md file. All subsequent changes were made in the SPECIFICATIONS.md file. The user prompts told the IDE to read the SPECIFICATIONS.md file to update the app to reflect the changes in the requirements.
