# Overview
The objective of this Lab is to build an app from a SPECIFICATIONS.md file. The learner should:
- Come up with an app idea that is sufficiently interesting and complex
- Create an folder and open the folder in the IDE.
- Create a SPECIFICATIONS.md file in the folder. Write an app description in the SPECIFICATIONS.md file that is complete enough that a competent SWE will be able to build an app based on the information provided in the file.
- Use the Chat in the IDE to build the app based on the SPECIFICATIONS.md file. 

More often than not, the SPECIFICATIONS.md file will need to be updated as the app is being built. This is expected. The goal is to create a SPECIFICATIONS.md file that covers all the aspects of the app and is easy to understand and follow.

The example in this folder shows 2 projects. The first project is a "Plan-then-Build" project, where the SPECIFICATIONS.md is created first, and then the app was built based on the file. When there were missing features or functionalities, the SPECIFICATIONS.md file was updated to include the missing desired features or functionalities. The IDE Chat was asked to reread the file and build the app based on the updated file. This process was repeated until a working version of the app was built.

The second project was built using the updated SPECIFICATIONS.md file from the first project as a starting point. This was done to check whether the prompts used in the first project would affect the outcome of the app being built. It is not necessary for the learner to do the same. The learner can just build only 1 app.




# Objective: Build an application guided by a SPECIFICATIONS.md file.

## Instructions:
- **Ideation**: Choose an app concept that is sufficiently complex and interesting.
- **Setup**: Create a new folder, open it in your IDE, and add a SPECIFICATIONS.md file.
- **Specification**: Write a comprehensive description of the app in SPECIFICATIONS.md that provides enough detail for a competent software engineer to build it.
- **Implementation**: Use the IDE's Chat feature to develop the application based on your SPECIFICATIONS.md file.

## Iteration & Process
It is expected that you will need to update the SPECIFICATIONS.md file throughout development. Keep the file updated, clear, and easy to follow as your application evolves.

## Examples

### Project 1
(Plan-then-Build): The specifications were created first, then the app was built. If features were missing or needed refinement, the file was updated, and the IDE Chat was prompted to re-read it to build the updated version. This cycle continued until a working application was complete.

### Project 2
This project used the final specifications from Project 1 to test how different prompts affect the build process. This step is optional; you only need to build one app.
